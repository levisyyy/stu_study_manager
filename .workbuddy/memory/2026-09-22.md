## 咨询：HLS 私有加密 SimpleAES 接入方案

- 结论：SimpleAES 必须用腾讯云超级播放器 TCPlayer（appID+fileID+psign）播放，xgplayer/hls.js 无法解密私有加密流；iOS Safari/iOS 微信不支持 Web 端私有加密（学员若以 iPhone H5 为主需谨慎选型）。
- 接入要点：控制台用 SimpleAES 加密模板转自适应码流（预置 SimpleAesEncryptPreset / 模板12，按量计费）→ 后端签名派发服务生成 psign（开发期可用控制台播放器签名工具）→ 前端引入 TCPlayer v5（CDN tcsdk.com，5.0+ 需免费基础版 License，localhost 免校验；容器必须是 video 标签）。
- 若决定接入：player.html 需改造为 xgplayer（直链课节）与 TCPlayer（VOD 加密课节）双模式，courses.js 数据结构加 type 字段。

## 实施：双模式播放页 + SimpleAES 课节接入

- 用户提供 `adp.12.m3u8`（模板12输出），子流含 `#EXT-X-KEY ... drm.vod2.myqcloud.com ... drmType=SimpleAES`，确认为 SimpleAES 加密流，直链不可播。
- 从 URL 解析出 appID=1257306140；注意：fileID 不能用 URL 里的 `b4105d3e5001834821483851066`（内部存储键，签名工具会报"file id有误"），正确 fileID 是控制台媒资列表显示的 `5001834821483851066`（视频：送外卖的小猫.mp4），已更正到 courses.js。
- `player.html` 改为双模式：默认 xgplayer（直链）；`type:"vod"` 走 TCPlayer（appID+fileID+psign），容器为隐藏切换的 `<video id="tc-player">`。psign 为空时显示填写指引。
- TCPlayer v5.3.4 + hls.js 1.5.20 已下载到 `libs/tcplayer/`（tcsdk.com + jsdelivr）。
- `courses.js` 新增 lesson3（type vod，psign 待用户从控制台播放器签名工具生成后填入）；列表页无需改动。
- 待办：用户填 psign 后验证加密播放；上线前需申请 TCPlayer 免费基础版 License（localhost 免校验）；iOS Safari/iOS 微信无法播放 SimpleAES。
- 用户已自行填入 psign（fileID 5001834821483851066，privateEncryptionDefinition 12），报错 Error 55 "Lack license url"：TCPlayer 5.x 必传 licenseUrl，localhost 下不校验有效性——已在 player.html 加占位 licenseUrl、courses.js 加 licenseUrl 字段（正式部署需填真实免费 License 地址）。
- 又报 Error 56 "Get license data failed"：占位地址拉不到数据。读 TCPlayer 源码发现 license 校验被 js-armor VM 混淆（不可读），仅确认备用 license 域名 license.vodplayvideo.net 等。对策：项目根放 `v_cube.license`（内容 `{}`），licenseUrl 指向 http://127.0.0.1:8088/v_cube.license（已确认 200），赌"localhost 跳过域名校验、仅要求 fetch 成功"。若仍报错则让用户去视立方控制台免费申请 Web 基础版 License 填真实地址。

- 又报 Error 52 Domain verification failed（License 绑 lessyysry.com vs 页面 localhost）。解法：TCPlayer 5.2.0+ 初始化参数 `domain` 手动传绑定的域名——player.html 已支持 `course.domain`，lesson3 已填 `lessyysry.com`。等用户复测。
- 排错链路汇总（SimpleAES 本地调试）：55=缺 licenseUrl 参数 → 56=licenseUrl 拉取失败 → 52=License 绑定域名与页面域名不符（用 domain 参数解决）→ 52 修复后"一直加载中"：原因是当初给 TCPlayer 配了 jsdelivr 标准版 hls.js 1.5.20，TCPlayer 检测到 window.Hls 直接使用，标准版不认私有密钥协议。已下载官方 release.zip（tcsdk.com/player/tcplayer/release/v5.3.4/release.zip），用定制版 `libs/hls.min.1.1.8.js`（562KB）替换标准版，另复制 tcpcrypto.1.0.0.js 与 safe-check 插件到本地备用（主 JS 仍会从 tcsdk CDN 动态加载 crypto/safecheck，可达）。等用户复测。
